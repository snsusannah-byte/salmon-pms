## 成品定义深度方案讨论（23:32）

### 实际产品矩阵
- 纯享装系列：8个规格（鱼腩200g+中段200g / 中段400g / 鱼腩400g / 尝鲜鱼中段100g / 尝鲜鱼腩100g / 尝鲜装75g / 中段200g / 中段400g+鱼块160g / 鱼头+鱼尾+鱼骨）
- 拼盘装系列：2个规格（生鲜130g+15只甜虾 / 中段200g+甜虾+希鲮鱼籽）
- 即食装系列：3个规格（现切400g / 整段400g / 现切分享装600g）
- 团购装系列：2个规格（团购装250g / 团购装200g）
- 赠品：鱼头（不定时赠送）

### 核心问题诊断
1. SPU=规格（本末倒置）：模板名"鱼腩200g+中段200g"是规格不是产品概念
2. 系列缺失：纯享装系列有8个规格，当前每个规格一个模板
3. 拼盘装是组合产品：三文鱼+甜虾+希鲮鱼籽，当前BOM只支持三文鱼物料
4. 品牌差异=包装腰封差异，被过度建模
5. 副产品独立生命周期：鱼头赠品/鱼头鱼尾鱼骨套装

### 4个方案对比
- 方案A：最小改动（加series字段，不动表结构）
- 方案B：加系列层+规格分离（推荐短期）— 新建 product_series + product_specs 表
- 方案C：完整重构（品类→系列→SPU→规格→SKU）+ 价格体系升级 + BOM打通全品类
- 方案D：最简方案（规范编码体系，不拆系列）

### 推荐路线
- 短期：方案D+方案A混合 — 加series字段，规范编码
- 中期：方案B — 新建 product_series + product_specs 表，规格从模板分离
- 长期：方案C — 四级结构重构，动态规格组合，完整价格体系

### 关键决策点
- 未来SKU>20款 → 必须方案B
- 拼盘装扩展更多组合 → 必须改BOM支持全品类
- 需要按系列做销量分析 → 必须加 series 层
- 副产品独立定价销售 → 必须拆分
- 判断：当前已有15+款，拼盘装在扩展，建议直接上方案B

### 短期行动建议
1. 立即做（不改表结构）：给 product_templates 加 series 字段，规范模板编码和名称，拼盘装配套商品支持非三文鱼产品
2. 中期做（改表结构）：新建 product_series 表，规格从模板分离到独立表，打通 finished_product_sale_items → variant_id
3. 长期做（重构）：四级结构，动态规格组合，完整价格体系
